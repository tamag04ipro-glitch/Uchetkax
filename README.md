# Учетка

MVP Android-приложения для локального учета служебного времени.

## Возможности
- локальный пароль без учетной записи;
- личный состав;
- учет часов по датам;
- тип события и основание/примечание;
- журнал;
- сводка;
- CSV-экспорт;
- полностью локальная SQLite база.

## Сборка
GitHub Actions workflow `.github/workflows/build.yml` собирает `app-debug.apk`.

Это технический MVP. Нормативные правила должны быть дополнительно проверены по действующим на дату релиза документам и локальным требованиям.
